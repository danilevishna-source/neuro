# НЕЙРО СТУДИЯ

Креативы и digital под ключ. Статический сайт на HTML, CSS и JavaScript.

## Запуск

`python3 -m http.server 8000`

## Публикация

GitHub Pages публикуется через GitHub Actions при каждом обновлении ветки `main`. В Settings → Pages выберите источник GitHub Actions.

Редактируйте `index.html`, `style.css` и `app.js`.
